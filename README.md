# Chai AI — Installation Guide

This guide explains how to download and install **Chai AI** on an Android device using the APK.

---

## 📱 Requirements

Before installing Chai AI, make sure you have:

- An Android smartphone
- An active internet connection
- Sufficient free storage
- The latest `Chai-AI-v1.0.apk` file

> Note: Chai AI is currently distributed as an APK and is not available on the Google Play Store.

---

## 1. Download the APK

1. Open the **Chai AI GitHub repository**.
2. Go to the **Releases** section.
3. Open the latest release, for example:
   `Chai AI v1.0`
4. Scroll down to the **Assets** section.
5. Download:

Chai-AI-v1.0.apk


6. Wait for the download to complete.

---

## 2. Open the Downloaded APK

After the download is complete:

1. Open your phone's **Files** or **File Manager** application.
2. Open the **Downloads** folder.
3. Find:

```text
Chai-AI-v1.0.apk
```

4. Tap the APK file to start the installation.

---

## 3. Allow Installation from Unknown Sources

Since Chai AI is installed directly using an APK instead of the Google Play Store, Android may display a security warning.

You may see a message such as:

> For your security, your phone currently isn't allowed to install unknown apps from this source.

If this appears:

1. Tap **Settings**.
2. Find **Allow from this source**.
3. Turn it **ON**.
4. Press the **Back** button.

You should now return to the APK installation screen.

> The exact location and wording of this setting may vary depending on your Android device and Android version.

---

## 4. Install Chai AI

Once you return to the installation screen:

1. Tap **Install**.
2. Wait while Android installs Chai AI.
3. Do not close the installation screen while the installation is in progress.
4. Once installation is complete, Android will display an **App installed** message.

---

## 5. Open Chai AI

After installation, you can launch the application in either of these ways.

### Option 1 — Open Immediately

Tap:

**Open**

### Option 2 — Open from the App Drawer

1. Open your phone's app drawer.
2. Search for:

```text
Chai AI
```

3. Tap the **Chai AI** icon.

---

## 6. Start Using Chai AI

After opening the application:

1. Start a new conversation.
2. Type your message in the chat box.
3. Send your message.
4. Wait for the AI response.

An active internet connection is required for AI responses.

---

## 🌐 Internet Requirement

Chai AI requires an internet connection to communicate with its AI backend.

Make sure either:

* Wi-Fi is enabled, or
* Mobile data is enabled.

Without an internet connection, AI responses may not work.

---

## ❗ Troubleshooting

### App Not Installed

If Android displays:

```text
App not installed
```

try the following:

1. Make sure the APK download completed successfully.
2. Delete the downloaded APK.
3. Download the APK again from the latest GitHub Release.
4. Make sure your device has enough free storage.
5. If an older version of Chai AI is installed, try updating it with the latest APK.

---

### Can't Install Unknown Apps

If Android doesn't allow the installation:

1. Open **Settings**.
2. Search for:

```text
Install unknown apps
```

3. Select the application you used to open the APK, such as Chrome or Files.
4. Enable:

```text
Allow from this source
```

5. Return to the downloaded APK.
6. Open the APK again and tap **Install**.

---

### APK Doesn't Open

If tapping the APK does not start the installation:

1. Open your **File Manager**.
2. Go to the **Downloads** folder.
3. Locate `Chai-AI-v1.0.apk`.
4. Tap the file again.
5. Follow the Android installation instructions.

---

### AI Is Not Responding

If Chai AI opens but does not return AI responses:

1. Check your internet connection.
2. Open a website in your browser to confirm that your internet is working.
3. Close Chai AI completely.
4. Open Chai AI again.
5. Send another message.

If the problem continues, the AI backend may temporarily be unavailable.

---

## 🔄 Updating Chai AI

When a newer version becomes available:

1. Open the GitHub **Releases** section.
2. Download the latest APK.
3. Open the downloaded APK.
4. Tap **Install**.
5. Android will update the existing Chai AI installation.

> If Android does not allow the update, uninstalling the previous version may be required. Note that uninstalling the app can remove its locally stored data.

---

## 🗑️ Uninstalling Chai AI

### Method 1

1. Press and hold the **Chai AI** app icon.
2. Tap **Uninstall**.
3. Confirm the uninstall.

### Method 2

Go to:

```text
Settings → Apps → Chai AI → Uninstall
```

Then confirm the uninstall.
